Vice City Cover Studio turns any photo and caption into GTA 6-style multi-panel cover art, exported as a PNG to share. It runs fully offline in a desktop browser — photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
